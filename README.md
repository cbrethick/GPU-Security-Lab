# GPU-Based Password Security Lab

**GPU-Based Password Cracking — An Educational Deep Dive**

An interactive, defensive cybersecurity learning platform that demonstrates password strength, cryptographic hashing, GPU parallel-computing concepts, and why modern password storage relies on slow, salted, memory-hard algorithms.

> ⚠️ Educational lab only. All data is synthetic, all targets are fictional and generated by the app, and all GPU figures are clearly labeled **"Educational Simulation — Not a Real GPU Benchmark."** Nothing can be pointed at real accounts, real hashes, or external systems.

## Features

| Module | What it does |
|---|---|
| **Overview** | Simulated CPU/GPU metrics, throughput & hash-algorithm charts, interactive security score, recent experiments, parallelism visualization |
| **Password Analyzer** | Local-only analysis: length, character classes, repeats, sequences, keyboard walks, dictionary/leetspeak, years/dates, entropy, 5-level meter, guessing-time estimates, suggestions, passphrase generator |
| **Hash Lab** | SHA-256 / SHA-512 / SHA-1 (Web Crypto) and MD5 (educational JS), normalization workflow, avalanche-effect diff, hashing vs encryption, measured browser hash speed |
| **GPU Simulation** | Real CPU-calibrated workload + transparent CPU-core vs GPU-lane model, live progress, core/lane visualizations, speedup scaling chart, WebGPU-ready engine interface |
| **Attack Simulation** | Dictionary demo against an app-generated fictional hash (30-word built-in list), brute-force search-space calculator, pattern-based guessing with synthetic examples |
| **Security Insights** | MD5 / SHA-1 / SHA-256 / bcrypt / Argon2 interactive comparison, salts, memory-hardness, MFA, credential reuse |
| **Experiment History** | Search, filter, sort, delete, clear, CSV export (metadata only) |
| **Report Generator** | Editable report with live preview → PDF and CSV download |
| **Settings** | Accent/surface themes, animation toggle, simulation speed, reset data, about, team |

## Privacy

- Passwords are analyzed in page memory only — never transmitted, never written to local storage or history.
- `localStorage` holds only safe experiment metadata and UI settings (fields are whitelisted on save).
- No backend. No analytics.

## Run locally

Requires Node.js 18+.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # production build into dist/
npm run preview    # serve the production build
```

## Deploy

Configured for Vercel (`vercel.json`): framework **Vite**, build `npm run build`, output `dist`.
